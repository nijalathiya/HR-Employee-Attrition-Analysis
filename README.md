# HR Employee Attrition Analysis

## Project Overview
This project focuses on analyzing HR employee data to understand employee attrition and identify factors that may influence employees to leave an organization. It uses data visualization and Machine Learning techniques to generate useful insights and predict employee attrition.

## Objectives
- Analyze employee data and identify important patterns.
- Perform data cleaning and preprocessing.
- Visualize employee information using charts and graphs.
- Build and compare Machine Learning models.
- Predict whether an employee is likely to leave or stay.
- Provide HR recommendations to help reduce employee attrition.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data Loading
2. Exploratory Data Analysis (EDA)
3. Data Cleaning and Preprocessing
4. Data Visualization
5. Feature Selection and Model Preparation
6. Machine Learning Model Training
7. Model Evaluation and Comparison
8. Employee Attrition Prediction
9. HR Recommendations

## Data Visualization
The project includes charts and graphs to explore employee data, identify patterns, and understand relationships between different employee attributes.

Visualizations include:
- Employee Data Analysis
- Correlation Heatmap
- Attrition Analysis
- Model Evaluation Charts
- Confusion Matrix

## Machine Learning Models
The project uses and compares the following Machine Learning algorithms:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier

The models are evaluated using suitable classification metrics to compare their performance.

## Prediction
The trained model predicts whether an employee is likely to:

- **Stay** in the organization
- **Leave** the organization

The prediction can help HR teams identify potential employee attrition risks.

## HR Recommendations
1. Improve employee satisfaction and engagement.
2. Review salary and benefits regularly.
3. Provide career growth and learning opportunities.
4. Monitor workload and work-life balance.
5. Identify employees at risk of leaving and take preventive action.
